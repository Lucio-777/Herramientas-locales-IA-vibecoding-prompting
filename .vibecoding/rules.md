# Reglas de Desarrollo del Proyecto (VibeCoding Local)

## Convenciones de Código
- Usar TypeScript estricto siempre con tipado explícito en interfaces y funciones.
- Mantener las funciones modulares, cortas y con una única responsabilidad.
- Para estilos, respetar las variables y temas nativos de VS Code (`--vscode-*`).
- Usar manejo de errores con bloques `try...catch` descriptivos.

## Filosofía del Agente
- Priorizar la privacidad y el uso de modelos locales en Ollama.
- Explicar las decisiones de arquitectura de manera clara y concisa en español.
